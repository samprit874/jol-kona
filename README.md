# 🌸 Jol Kona

**Jol Kona (জলকণা)** is a premium handmade gift and jewelry website designed to showcase beautifully crafted products with a warm, elegant, and mobile-first shopping experience.

The website reflects the emotion behind every handmade creation, combining minimal design, Bengali cultural aesthetics, and modern web technologies to create a luxurious browsing experience.

---

## ✨ Features

* 🎀 Elegant and minimal UI
* 📱 Fully responsive design
* 🌙 Dark theme with premium aesthetics
* 🛍️ Handmade product showcase
* 🔍 Product categories and filtering
* 📷 High-quality product gallery
* ❤️ Smooth animations and transitions
* ⚡ Fast loading and optimized assets
* 🎨 Bengali-inspired branding
* 📦 Easy-to-maintain project structure

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/samprit874/jol-kona.git
```

### Open the project

Navigate to the project folder and open **index.html** in your browser.

Or use **VS Code** with the **Live Server** extension for development.
